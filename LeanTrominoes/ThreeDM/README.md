# Three-dimensional matching

The paper's Section 3 three-dimensional matching problem, its SAT reductions, encodings, line and plane results. Colored-graph orientation and its normalization are under Graphs/Orientation.

The reorganization placed 416 existing modules here.

Import `LeanTrominoes.ThreeDM.Results` for the curated public results.

Useful entry points:

- [Planar 3DM presentations](PeriodicPlanarThreeDM.lean)
- [Finite planar gadgets](Gadgets/)
- [Local planar plane completeness](Plane/PeriodicThreeDMLocalPlaneCompleteness.lean)
- [Local planar line completeness](Line/PeriodicThreeDMPlanarLineCompleteness.lean)
- [Line completeness](Line/PeriodicThreeDMLineCompleteness.lean)

See the [repository overview](../../README.md#repository-organization) for the
paper map and the [maintenance guide](../../docs/organization.md) for import
migration and validation commands.
