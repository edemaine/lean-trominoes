# Reusable computation infrastructure

Generic TM2 machines, partial-recursive evaluators, stream encodings, unary and binary field machines, and reusable compiler combinators.

The reorganization placed 929 existing modules here.

Import `LeanTrominoes.Computation.Results` for the curated public results.

Useful entry points:

- [Alphabet restriction](TM2/TM2FiniteAlphabetRestriction.lean)
- [Sequential space composition](TM2/TM2SequentialSpace.lean)

See the [repository overview](../../README.md#repository-organization) for the
paper map and the [maintenance guide](../../docs/organization.md) for import
migration and validation commands.
