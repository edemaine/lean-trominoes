# Trichromatic graph orientation

Section 3 of the paper culminates in graph orientation. This directory contains
ordinary and normalized colored-graph orientation, finite/line/plane completeness,
encodings, decision procedures, and normalization from 3DM instances.
Program-source encodings are under Reduction/Program.

Import `LeanTrominoes.Graphs.Orientation.Results` for the public results.
