The paper's Section 2 drawing theory and graph algorithms from Section 4. Trichromatic graph orientation is under Orientation; ordinary and bipartite matching are under Matching.

The reorganization placed 2,508 existing modules here.

Import `LeanTrominoes.Graphs.Results` for the curated public results.

Useful entry points:

- [Generic periodic graph core](Core/PeriodicGraph.lean)
- [Graph-orientation results](Orientation/Results.lean)
- [Cubic polygonal drawing refinement](Drawings/Grid/PeriodicGridDrawingCubicRefinementTheorem.lean)
- [Periodic matching solver](Matching/PeriodicMatchingSolver.lean)
- [Period-one matching theorem](Matching/PeriodicMatchingPeriodOne.lean)
