# Complexity and certification

Finite-alphabet encodings, polynomial-time and polynomial-space machine interfaces, reductions, and finite-witness infrastructure. Domain-specific cost proofs stay with the corresponding algorithm or reduction.

The reorganization placed 71 existing modules here.

Import `LeanTrominoes.Complexity.Results` for the curated public results.

Useful entry points:

- [Complexity interfaces](Complexity.lean)
- [Finite-alphabet time certificates](FiniteAlphabetPolyTime.lean)

See the [repository organization guide](../../docs/organization.md) for the paper map, module migration, and validation commands.
